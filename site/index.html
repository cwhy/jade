Opening the playground…

A local collaboration demo. Your text stays in this browser tab.

Two independent editing clients share an in-memory authority. Nothing is uploaded or saved after you close or reload this page. This demonstrates editing behavior, not network performance.

Rich documents,
all the way down.

Paragraphs, lists, code blocks and image references can live inside table cells. The structure is part of the document, so your editor can work with more than a grid of text.
