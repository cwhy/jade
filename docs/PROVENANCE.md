# Development provenance

jade began as an independent rich-document engine prototype. This public alpha consolidates its five packages and standalone regression corpus into a self-contained repository.

Public preparation changes package names, packaging metadata, documentation, formatting and stale development comments. Editing behavior is kept under the unchanged regression assertions. Synthetic test fixtures remain in the repository; private application records, machine-local logs and application adapters are not distributed here.

The external-root inventory records integration tests that require a host application. It is traceability, not an assertion that those tests run in this repository.

If you contribute third-party code or adapt a test, retain its required copyright/license notices and identify the source in the contribution. Source availability by itself is not permission to relicense code.
